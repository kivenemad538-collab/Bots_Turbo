تحديث موقع وبوت ليجند

1. ارفع محتويات ملفات الموقع فوق النسخة الحالية في GitHub Pages.
2. ارفع محتويات البوت فوق النسخة الحالية في مستودع Railway وشغّل Deploy.
   لا تحذف قاعدة البيانات أو الـVolume. لا تغير DATA_FILE أو DATABASE_URL.
   Node 22 مطلوب، وتم تضمين إعداد الإصدار وpackage-lock.json.
3. Railway Variables:
   API_PUBLIC_URL=https://botsturbo-production.up.railway.app
   FRONTEND_URL=رابط موقع GitHub Pages الحالي كاملاً
   اترك DISCORD_BOT_TOKEN وDISCORD_CLIENT_SECRET في المتغيرات فقط.
4. Discord Developer Portal > OAuth2 > Redirects:
   https://botsturbo-production.up.railway.app/auth/discord/callback
5. صلاحيات البوت في انتظار الدعم 1522093063072383138:
   View Channel + Connect + Speak
   امنح البوت أيضاً Send Messages + Embed Links في رومات الإعلانات.
6. أمر /اعلان:
   Server Settings > Integrations > البوت > Commands > اعلان
   الأمر مغلق افتراضياً: اسمح للرتبة 1560384331858452560 فقط واحفظ.
   Discord يسمح للأدمن برؤية الأوامر، لكن كود البوت يمنع الإرسال دون هذه الرتبة.
   اكتب /اعلان واختر الروم، ثم اكتب العنوان والرسالة في النموذج.
   الرسالة Embed أزرق باسم LEGEND ROLEPLAY وصورة السيرفر والتوقيت.
   المنشنات لا ترسل تنبيهات جماعية تلقائياً.
7. انتظار الدعم:
   البوت يدخل الروم عند التشغيل ويعيد الاتصال تلقائياً.
   عند دخول شخص يرسل له رسالة خاصة ويشغّل الترحيب الصوتي الموجود في جذر ملفات البوت باسم welcome.ogg.
   نص الصوت: مرحبًا بك في الدعم الفني الخاص بسيرفر ليجند. يرجى الانتظار، وسيكون أحد أعضاء الدعم معك قريبًا.
   الصوت ثابت وليس محادثة ذكاء اصطناعي. لا يحتاج API أو خدمة نطق وقت التشغيل.
   منع تكرار الترحيب خلال 30 ثانية، والرسائل الخاصة تتطلب أن يسمح العضو باستقبالها.
8. بعد النشر افتح الموقع مع Ctrl+F5 وجرب التسجيل.

التحقق المحلي: فحص JavaScript وملف الصوت والروابط. اختبار Discord الفعلي يحتاج نشر النسخة وتشغيل البوت بصلاحياته.
