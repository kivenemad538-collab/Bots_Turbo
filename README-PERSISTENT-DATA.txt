TURBO RP - حفظ البيانات عند تغيير حساب Railway

تم إضافة طريقتين للحماية:
1) PostgreSQL خارجي عبر DATABASE_URL (الموصى به).
2) Backup/Restore للمانجر من لوحة التحكم.

مهم جدًا:
- لو حذفت مشروع Railway القديم قبل إخراج نسخة Backup، أي turbo-db.json موجود فقط داخل المشروع القديم لا يمكن استرجاعه بعد الحذف.
- قبل حذف المشروع القديم: افتح لوحة التحكم بحساب المانجر واضغط تنزيل نسخة احتياطية.
- في المشروع الجديد: حط نفس Variables + DATABASE_URL لقاعدة PostgreSQL خارجية، وبعدها ارفع ملف النسخة الاحتياطية من لوحة التحكم.
- بعد كده كل التقديمات، الحالات، أسباب الرفض، المواعيد، الأدمن المضافين، الإعدادات، والـ audit تحفظ في PostgreSQL وتفضل موجودة حتى لو عملت Redeploy أو غيرت حساب Railway، بشرط إن قاعدة البيانات الخارجية نفسها ما تتمسحش.

Variables الجديدة:
DATABASE_URL=postgresql://...
PGSSLMODE=   (اختياري)
